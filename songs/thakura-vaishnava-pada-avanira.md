# Тха̄кура-вайшнава-пада

### Шрīла Нароттам Да̄с Тха̄кур

#### 1

    тха̄кура-вайшнава-пада,    аванīра сусампада,
        шюно бга̄і! хоія ека мана
    а̄шроя лоія бгадже,    та̄ре кришна на̄хі тьядже
        а̄ро саба море ака̄рана

> **тха̄кура** — святого; **вайшнава** — вайшнава; **пада** — стопи; **аванīра** — усього світу; **сусампада** — найбільше дорогоцінний скарб; **шюно** — слухай; **бга̄і** — брате; **хоія** — ставши, зробившись; **ека** — одним; **мана** — розум; **а̄шроя** — притулок; **лоія** — прийнявши; **бгадже** — той хто поклоняється; **та̄ре** — його; **кришна** — Крішна; **на̄хі** — не; **тьядже** — покидає; **а̄ро** — решта; **саба** — усе; **море** — гине; **ака̄рана** — без причини, марно.

#### 2

    вайшнава-чарана-джол,    према-бгакті діте бол,
        а̄ро кехо нахе балаванта
    вайшнава-чарана-рену,    мастаке бгӯшана віну
        а̄ра на̄хі бгӯшанера анта

> **вайшнава** — вайшнава; **чарана** — стоп; **джол** — вода; **према** — любовної; **бгакті** — відданісті; **діте** — дарує; **бол** — силу; **а̄ро** — інший; **кехо** — хтось; **нахе** — не є; **балаванта** — на це спроможний; **вайшнава** — Вайшнава; **чарана** — зі стоп; **рену** — пил; **мастаке** — на голову; **бгӯшана** — прикраса; **віну** — окрім (єдина); **а̄ра** — іншої; **на̄хі** — немає; **бгӯшанера** — прикраси; **анта** — довершеної.

#### 3

    тīртха-джол-павітра-ґуне,    лікхіячхе пура̄не,
        се саба бгактіра праваньчана
    вайшнавера па̄да-дока,    сама нахе еі саба,
        джа̄те хоя ва̄ньчіто пӯрана

> **тīртха** — святих місць паломництва; **джол** — води; **павітра** — священні; **ґуне** — завдяки якості; **лікхіячхе** — так написано; **пура̄не** — у Пуранах; **се** — цього; **саба** — усього; **бгактіра** — для отримання любовної відданості ; **праваньчана** — недостатньо; **вайшнавера** — вайшнави; **па̄да** — стопа; **дока** — вода; **сама** — рівне; **нахе** — не є; **еі** — це; **саба** — усе; **джа̄те** — завдяки якій; **хоя** — стає; **ва̄ньчіто** — бажане; **пӯрана** — сповненим.

#### 4

    вайшнава-санґете мана, а̄нандіта анукшана,
        сада̄ хой кришна-парасанґа
    дīна нароттама ка̄нде, хія дгайрджа на̄хі ба̄ндге,
        мора дошя кено хоіло бганґа

> **вайшнава** — у Вайшнава ; **санґете** —товаристві ; **мана** — ум; **а̄нандіта** — радісний; **анукшана** — щомиті; **сада̄** — завжди; **хой** — буває (ведуться); **кришна** — (про) Крішну; **парасанґа** — розмови; **дīна** — убогий; **нароттама** — Нароттама Дас; **ка̄нде** — плаче; **хія** — серце; **дгайрджа** — терпінням; **на̄хі** — не; **ба̄ндге** — утримується; **мора** — моє; **дошя** — вада, недолік, нещастя; **кено** — чому; **хоіло** — сталося; **бганґа** — руйнування, падіння.
